How CyberMastery Works

📘 Learning Phase

Complete learning modules to understand cybersecurity concepts and prepare for missions.

🎯 Mission Phase

Complete 10 levels per mission to unlock escape rooms. Each level gives XP based on attempts:

  • +10 XP First attempt correct
  • +5 XP Second attempt correct
  • +2 XP Third+ attempt correct
  • -3 XP Any wrong answer

� Multiplayer Challenges

Compete against other players in real-time cybersecurity challenges!

  • +150 XP Winner of multiplayer challenge
  • 🎯 Create challenge room with 6-character code
  • ⏱️ 10-minute timer for each challenge
  • 🎮 Both players get same 10 missions
  • 🏆 Winner determined by highest score
  • ⏳ Wait for both players to complete
  • 📊 Real-time progress tracking

�� Escape Room Phase

Solve cybersecurity puzzles to complete missions. Higher rewards for accuracy:

  • +50 XP First attempt escape
  • +30 XP Second attempt escape
  • +10 XP Third+ attempt escape
  • -3 XP Wrong answers
  • No XP Replaying completed rooms

🏅 Badge System

Earn badges by completing missions:

  • 🏆 Cyber Beginner Complete 2 missions (+20 XP)
  • 🏆 Cyber Expert Complete 5 missions (+50 XP)

🏆 Competition

Compete on leaderboards and climb the ranks with your XP!
